# Phoenix Developer Portfolio 🚀

A modern, cinematic developer portfolio landing page inspired by the **Videaste - Personal Videographer Portfolio Landing Page** Dribbble design by Adhiari Subekti.

## 🌟 Key Features
- **Videaste Design System**: Ultra-sleek dark mode obsidian & charcoal palette (`#08090C`, `#0F111A`) with gold and cyan glows.
- **Google Badges & Certifications**: Prominent section showcasing official Google Cloud, AI, Android, and Cybersecurity badges with interactive credential verification modals (PMOS excluded).
- **Featured Projects Grid**: Showcase of web applications, AI interfaces, and productivity platforms with filter tabs.
- **Interactive Video Player Showcase**: Hero section reel preview with interactive play modal.
- **Responsive Layout**: Glassmorphic sticky header, mobile drawer menu, and clean typography (`Syne`, `Outfit`, `Inter`).

## 🛠️ Built With
- **HTML5 & CSS3**: Modern layouts, custom properties, glassmorphism, responsive CSS grid/flexbox.
- **Vanilla JavaScript**: Filter tabs, modal dialogs, navigation state, and form interactions.
- **Google Web Fonts & Material Symbols**: `Syne`, `Outfit`, `Inter`, `Space Grotesk`.
